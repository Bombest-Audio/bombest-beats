  <action>
Create a `ci` user account on `https://beats.bom.best` using the `/auth/register` endpoint.
The invite code `whatupdoe` is a valid community invite code accepted by the backend.

Run this curl command:
```bash
curl -s -X POST https://beats.bom.best/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"ci","password":"<CHOOSE_A_STRONG_PASSWORD>","invite_code":"whatupdoe"}' | python3 -m json.tool
```

Choose a strong password (16+ chars). Record it — you will need it for the GitHub secret.

Expected success response:
```json
{"message": "User registered successfully", "user_id": <N>}
```

If `ci` username is already taken, the response will be:
```json
{"error": "Username already taken"}
```
In that case, verify you can log in with existing credentials before proceeding.

After creating the account, verify login works:
```bash
curl -s -X POST https://beats.bom.best/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"ci","password":"<YOUR_PASSWORD>"}' | python3 -m json.tool
```
Expected: response contains `access_token`.
